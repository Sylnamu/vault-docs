# The Builder Pattern in Java

This documentation set covers the Builder creational pattern as it is used in
Java. It is written as four separate pieces, each serving a different need.
Choose the piece that matches what you are doing right now.

## Learning by doing

**[Your First Builder](tutorial.md)** - A guided lesson that takes you from an
empty file to a working `UserProfile` builder, one step at a time. Start here
if you have never implemented the pattern and want a single path that is
guaranteed to work.

## Working towards a goal

**[How to construct objects with the Builder pattern](how-to.md)** - Short,
task-focused directions for common jobs: replacing a telescoping constructor,
validating at build time, keeping objects immutable. Use these when you
already know what you want to achieve.

## Working and need facts

**[Builder Pattern Reference](reference.md)** - The participants, contracts,
variants and constraints of the pattern, described plainly. Consult it while
coding when you need the exact shape of something.

## Learning to understand

**[About the Builder Pattern](explanation.md)** - Why the pattern exists, how
it compares with constructors, setters and factories, and when it is
overkill. Read it when you want the bigger picture.

## Suggested paths

- New to the pattern? Tutorial first, then reference open beside you as you code.
- Applying it to an existing codebase? How-to guide first, with the reference beside it.
- Deciding whether your team should adopt it? Explanation first.
