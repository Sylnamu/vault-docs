# 买断制非游戏桌面应用发布指南（个人笔记）

> 目标：一个人能卖、能收款、能持续分发。买断制 = 一次付费、永久/大版本买断。

## 1. 推荐组合（结论）

官网直发为主，商店为辅：

`官网 + 支付网关 + Microsoft Store + Mac App Store（可选） + Steam（看类型） + winget`

* 官网：定价自由、无抽成、用户归自己，是买断制的基本盘
* 商店：带来搜索流量和信任背书，但要接受抽成和审核

## 2. How-to：发布流程

### 2.1 官网直发

1. 打包：Windows 出 `MSIX / exe`，macOS 出 `dmg + 公证`
2. 接支付：海外用 Merchant of Record，国内用微信/支付宝
3. 发 License Key：购买后邮箱发码，应用内激活
4. 接更新：Electron 用 `electron-updater`，Tauri 用自带 updater，macOS 可用 `Sparkle`

### 2.2 上架商店

1. Windows：先上 Microsoft Store + winget，个人/公司注册目前都免费
2. macOS：如果要上 Mac App Store，提前做沙盒适配和 IAP，官网版和商店版分开打包
3. Steam：建 Steamworks 应用，交 $100，准备商店页、demo、版本分支

### 2.3 国内分发（Windows 为主）

腾讯软件管家、360软件管家、联想/华为应用商店 + 官网包。先准备软著、应用说明、无捆绑安装包，过审更快。

## 3. Reference：渠道对照表

| 渠道 | 费用 / 抽成 | 适合 | 注意 |
| --- | --- | --- | --- |
| 官网 + Lemon Squeezy / Paddle | 约 5% + $0.5/笔，包全球 VAT/GST 代报 | 海外买断制首选 | Lemon 海外卡/PayPal 有附加费，Paddle 国际费全包 |
| 官网 + Stripe 直连 | 约 3% + 固定费 | 有公司能自己处理税时最省 | 税、发票、VAT 全部自己扛 |
| 官网 + 微信支付/支付宝 | 约 0.6% / 0.6% | 国内买断制 | 需个体户/公司主体 + 域名备案 |
| Microsoft Store | 用微软支付抽 15%，非游戏用自家支付 0% | Windows 必上 | 非游戏才能用第三方支付免抽成 |
| Mac App Store | 年费 $99，小企业 <$1M 抽 15%，否则 30% | 要苹果搜索流量时上 | 必须 IAP + 沙盒，功能受限 |
| Steam | $100/款，$1000 后返还，分成 30% 起 | 工具/效率/设计类买断制可试 | 用户偏游戏，需做商店页和折扣 |
| itch.io | 自定义分成，可 0% | 冷启动、小工具 | 流量小，无审核优势 |
| winget | 免费 | Windows 技术用户导量 | 只是分发，无支付 |
| Gumroad | 10% + 附加处理费 | 不推荐主力，临时卖可以 | 同为 MoR，比 Lemon/Paddle 贵 |

> 数据基线：2026-10。商店政策常变，上架前以官方费率页为准。

## 4. 买断制特别注意

1. **授权模式先定好**：一机一码 / 可换机几次 / 大版本付费升级。写进购买页，减少纠纷。
2. **商店内不能外跳支付**：苹果和微软商店内走 IAP，就要接受抽成。想 0 抽成只能官网卖。
3. **试用策略**：商店版用功能限制 + Pro 解锁，Steam 用 `本体 + DLC` 或 `demo + 本体`，官网用试用期 + 激活码。
4. **税和发票**：海外优先 MoR 代扣代缴，国内要考虑普票/专票需求。
5. **防破解预期**：买断制一定会被破解，按“方便付费用户”做验证，别为难付费用户。
