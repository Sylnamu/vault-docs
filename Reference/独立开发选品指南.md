# 独立开发选品指南（个人笔记）

> 目标：一个人能做、能上线、能收到钱的产品。

## 1. 核心判断标准

先看这 4 个，再谈想法：

1. **谁付钱？** 用户 = 付费人最好。用户是学生、普通 C 端，付费意愿通常很低。
2. **怎么找到他们？** 能说出具体获客渠道才算数：SEO 关键词、抖音/小红书、行业群、线下转介绍。想不出渠道 = 不要做。
3. **是不是高频刚需？** 最好是工作流里的痛点（每天/每周都要用），而不是“有了更好”。
4. **一个人能维护吗？** 避开重客服、重审核、重线下履约的模式。

一句话公式：**明确付费人群 + 可搜索/可触达 + 小而痛 + 低运维 = 好方向**

## 2. 推荐做的 4 类

### A. 垂直行业小工具（最优先）
- 例子：跨境电商利润核算、律所合同归档、健身房约课、诊所排班
- 为什么好：需求具体、竞争小、大厂看不上、用户愿付费、口碑传播快
- 前提：你认识这个行业的 3-5 个人，能聊出真实流程

### B. 一次性买断工具
- 例子：批量改名、PDF 处理、截图标注、本地文件整理
- 优点：无服务器成本、无持续运维、交付即结束
- 缺点：无复利，需持续找新买家。适合接单过渡 + 积累现金流

### C. 微 SaaS（单点订阅）
- 只做一个功能，做到可收费即可，不要做平台。
- 例子：某平台的数据监控、定时报告、自动化同步
- 定价建议：30-100 元/月，100 个付费用户 = 可养活自己

### D. 产品化服务
- 先人工交付，再逐步自动化。最容易验证需求。
- 例子：帮人代建站 + 模板复用、帮商家做短视频代运营 + 工具提效

## 3. 建议避开的

- 社交/社区/内容平台：需要网络效应，个人冷启动做不动
- 纯 AI 套壳：无护城河，模型一升级就被替代。除非你有独家数据或分发渠道
- 面向“所有中小企业”：等于没有用户
- 重客服、重合规（金融/医疗诊疗/教育结果承诺）：一个人会被拖死

## 4. 动手前验证清单（写代码之前做完）

1. 列出 50 个目标用户在哪，加 10 个人聊聊
2. 做一个单页落地页，讲清楚：给谁、解决什么、多少钱
3. 看搜索需求：百度/微信/小红书/抖音搜一遍，看有没有人在问“XX怎么办”
4. 看竞品：有竞品且在收费 = 好事，说明有人付钱。没竞品多半是没需求
5. 预售：能收到 3-5 个意向付款（哪怕几十块），再开工

## 5. 技术与成本建议

- 一人栈越简单越好：Web 首选 Next.js / Nuxt + Supabase / LeanCloud；桌面用 Electron / Tauri；移动端优先微信小程序或单端 App
- 第一版 2-4 周必须上线收费版，别憋大招
- 上线指标：7 天有人用，30 天有人付费，90 天决定继续还是换方向

## 6. 备选方向池（可直接挑一个验证）

1. 某类商家的对账/报价/客户跟进小工具
2. 自媒体人的素材管理 + 自动排版 + 多平台发布
3. 打工人的求职/副业工具：简历优化、面试题库（垂直岗位）
4. 本地生意工具：预约、核销、会员复购提醒
5. 出海小工具：汇率利润计算、评论监控、物流跟踪聚合
