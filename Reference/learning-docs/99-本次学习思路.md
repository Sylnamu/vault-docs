## 3. 为什么是 next.js + L2

* next.js 三全：用户被赶出仓库（docs→官网、errors按码、UPGRADING跳转、Releases代Changelog）、贡献者留仓（contributing薄索引四象限）、Agent三层（AGENTS.md→skills→.github/AGENTS.md）。一把尺量三类。
* L2 是最小闭环：L1 跑不起来团队协作，L3 的 skills/CODEOWNERS/发版通道对新手是噪音。
