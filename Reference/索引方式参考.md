# 分层索引与导航方式参考

以下几个做法和“每个文件夹有自己的入口页、通过入口逐层导航”有关，但侧重点各不相同。可以按名称自行查阅。

## 1. Obsidian Folder Notes

为文件夹配一篇与该文件夹关联的笔记，让文件夹拥有可打开、可编辑的说明页或入口页。和“每个文件夹一张地图”最接近。

**搜索：** `Obsidian Folder Notes plugin`

## 2. Directory README / `index.md`

在目录中放置 `README.md` 或 `index.md`，说明该目录内容并链接到其中的页面或下一级目录。常见于代码仓库、文档站点和知识库。它是一种通用约定，不是单一产品或严格统一的规范。

**搜索：** `directory README index.md documentation navigation`

## 3. MOC（Map of Content）

用一篇笔记汇集并组织其他笔记的链接，也可以建立多层 MOC。和文件夹地图相似之处是“用链接作为导航入口”；不同之处是 MOC 通常按主题或问题组织，不必与文件夹一一对应。

**搜索：** `Nick Milo Maps of Content MOC nested MOC`

## 4. Zettelkasten Structure Note（结构笔记）

用结构笔记挑选、排序并串联相关卡片或笔记，形成主题入口或阅读路径。它强调知识之间的关系与组织逻辑，不只是列出目录中的文件。

**搜索：** `Zettelkasten structure note structure zettel`

## 对照时可以留意

- 入口页是按**文件夹**、**主题**还是**问题**组织？
- 是否逐层链接到下一级入口？
- 页面只是列链接，还是还提供简介、分类或推荐阅读顺序？
- 文件夹结构变化时，索引需要怎样维护？
